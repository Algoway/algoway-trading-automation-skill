# Trading Signal Execution Automation Skill

A public Agent Skill for understanding and troubleshooting automated trading workflows across TradingView, Telegram, webhooks, MetaTrader 5, brokers, exchanges, and other execution destinations.

The skill uses `SKILL.md` as its entry point and keeps detailed domain references in the `references/` directory.

## Structure

- `SKILL.md` — agent instructions and routing logic
- `references/index.md` — knowledge base entry point
- `references/tradingview-automation.md`
- `references/telegram-automation.md`
- `references/webhook-json-reference.md`
- `references/execution-platforms.md`
- `references/execution-behavior.md`
- `references/mt5-knowledge.md`
- `references/troubleshooting.md`
